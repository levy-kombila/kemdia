# ADR-0061 — CI : machines fixées sur Ubuntu 24.04

- **Statut** : Accepté
- **Date** : 2026-10-27
- **Tâche** : S8-T09 (CI bloquée sur toutes les PR)

## Contexte

Depuis le 2026-10-19, GitHub fait passer le libellé `ubuntu-latest` à Ubuntu 26, progressivement. À partir du
2026-10-26, toutes les PR (Dependabot #99 à #103 comprises) échouent au job « Bout en bout et performance » : l'étape
`playwright install --with-deps chromium` échoue sur cette image (paquets système de Chromium non pris en charge), donc
aucun test de bout en bout ni de performance ne tourne. Le dernier passage vert de `main` (2026-10-24) tournait encore
sur Ubuntu 24.04. Les autres jobs passent, mais sur une image qui change sans prévenir.

## Décision

1. Tous les jobs des workflows (`ci.yml`, `_deploy.yml`, `release.yml`, `security.yml`, `zap.yml`) tournent sur
   **`ubuntu-24.04`** au lieu de `ubuntu-latest`.
2. Le passage à une version plus récente d'Ubuntu se fera par une **tâche dédiée**, quand Playwright la prendra en
   charge, en vérifiant tous les jobs d'un coup.

Choix du 2026-10-27 : option recommandée retenue sans être reposée (ta demande du 2026-10-23).

## Conséquences

- La CI redevient verte et reproductible : un changement d'image ne casse plus les PR sans prévenir.
- Les PR Dependabot ouvertes repassent au vert après leur mise à jour depuis `main` (commentaire
  `@dependabot rebase`).

### Risques acceptés

- Ubuntu 24.04 recevra moins de mises à jour d'outils préinstallés que l'image la plus récente ; nos outils (Node,
  pnpm, Postgres, Gitleaks, Playwright) sont installés par le workflow à des versions fixées, donc l'effet est faible.
- GitHub retirera un jour l'image 24.04 (annoncé à l'avance) : il faudra alors faire la tâche de passage. Revue
  à l'ouverture de chaque sprint (relecture de sécurité, info) : vérifier si Playwright prend en charge Ubuntu 26.
- GitHub continue de livrer les mises à jour de sécurité de l'image 24.04 : la fixer ne fige pas ses correctifs.

## Alternatives écartées

- **Fixer seulement le job de bout en bout** : les autres jobs resteraient exposés au même type de rupture.
- **Installer Chromium sans `--with-deps`** ou avec des paquets ajoutés à la main sur Ubuntu 26 : fragile, et le
  navigateur testé ne correspondrait plus à celui que Playwright garantit.
- **Conteneur officiel Playwright pour le job** : changement plus large (services, chemins, cache) pour un gain nul
  tant que 24.04 est disponible.
